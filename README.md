# ClarusIQ

**ClarusIQ is a Power BI and data analytics consultancy for marketing agencies and in-house marketing teams.** It connects campaign, ad-platform, and CRM data into one validated model, builds decision-ready client reporting in Power BI, and applies AI only where it measurably improves a recurring reporting task.

Enrolled member of the Microsoft AI Cloud Partner Program.

## Services

- [Analytics & AI Strategy](https://www.clarusiq.com/services/strategy): a prioritized roadmap across data, reporting, and AI
- [Data Foundation](https://www.clarusiq.com/services/data-foundation): ad platforms, CRM, and billing data in one model with consistent metric definitions
- [Power BI Reporting](https://www.clarusiq.com/services/reporting): client-ready reports built on a single semantic model
- [Applied AI](https://www.clarusiq.com/services/applied-ai): AI for specific, recurring reporting tasks, grounded in validated data
